How it's calculated

Weighted return = the sum of (holding value × holding return) ÷ total value. Each holding's return counts in proportion to its share of the portfolio. Use the same kind of return for every holding, such as each fund's expected or past yearly return. Returns can be negative.

How to work out your portfolio's overall return

Your portfolio's return is not the simple average of each holding's return. Each holding counts in proportion to how much money is in it, so a large holding moves the total much more than a small one.

For example, ₹5 lakh earning 12%, ₹3 lakh earning 7%, ₹1.5 lakh earning 15% and ₹50,000 earning 6.5% give a weighted return of about 10.7% on ₹10 lakh, even though the simple average of the four returns is 10.1%.

Frequently asked questions

Should I use past or expected returns?

Either, but use the same kind for every holding. Past returns show how the portfolio did, and expected returns help you plan.

How does asset allocation affect the return?

Moving money between holdings changes their weights, and therefore the overall return and risk. The Asset Allocation Calculator helps you plan the mix.

What about money added at different times?

If you invested at different dates, the XIRR Calculator gives a more accurate return for a single fund.

How to use the Portfolio Return Calculator

Enter holding 1 value, holding 1 return (p.a.), holding 2 value, holding 2 return (p.a.), holding 3 value, holding 3 return (p.a.), holding 4 value, holding 4 return (p.a.). The calculator updates as you type and shows Weighted portfolio return, along with the figures behind it. It runs in your browser, so nothing you enter is sent anywhere. Use the Reset button to go back to the example values.
