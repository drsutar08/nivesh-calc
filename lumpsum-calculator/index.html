How it's calculated

What a one-time investment can grow into

A lump sum is a single investment left to grow for a number of years. The result depends on three things: the amount, the yearly return and the time. Time has the largest effect, because growth is earned on earlier growth.

Use the calculator to compare how the same amount behaves over 5, 10 and 20 years, or at different return assumptions. Returns here are assumed to be constant; real market returns are uneven.

Frequently asked questions

How do I calculate the future value of a lump sum?

Multiply the amount by (1 + annual return) raised to the number of years. The calculator does this for you.

Is the return guaranteed?

No. The return is an assumption you choose. Market-linked investments can lose value.

How is this different from a SIP?

A lump sum is invested all at once, while a SIP invests every month. See the SIP Calculator to compare.

How to use the Lumpsum Calculator

Enter investment amount, expected return (p.a.), duration. The calculator updates as you type and shows Estimated value, along with the figures behind it. It runs in your browser, so nothing you enter is sent anywhere. Use the Reset button to go back to the example values.
